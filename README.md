# GREEN-API Chat

Небольшой React/Vite интерфейс для отправки и получения сообщений через GREEN-API.

## Что нужно заранее

- Node.js 20 или новее
- npm
- Аккаунт GREEN-API
- `idInstance` и `apiTokenInstance` от вашего инстанса
- Активированный инстанс, привязанный к Telegram

## Установка

Склонируйте проект или откройте папку проекта, затем установите зависимости:

```bash
npm install
```

Если папка `node_modules` уже есть, этот шаг можно пропустить.

## Запуск в режиме разработки

```bash
npm run dev
```

После запуска Vite покажет локальный адрес в терминале. Обычно это:

```bash
http://localhost:5173
```

Откройте этот адрес в браузере.

## Как пользоваться

1. Введите `idInstance`.
2. Введите `apiTokenInstance`.
3. Нажмите `Открыть чат`.
4. Введите номер получателя в международном формате, только цифрами.

Пример:

```text
79991234567
```

5. Нажмите `Создать чат`.
6. Напишите сообщение и отправьте его.

Приложение отправляет сообщения через метод `sendMessage` и получает входящие сообщения через очередь уведомлений GREEN-API.

## Проверка проекта

Запустить линтер:

```bash
npm run lint
```

Собрать production-версию:

```bash
npm run build
```

Посмотреть собранную версию локально:

```bash
npm run preview
```

## Возможные проблемы

Если сообщение не отправляется, проверьте:

- правильно ли введены `idInstance` и `apiTokenInstance`;
- активен ли инстанс GREEN-API;
- указан ли номер получателя в международном формате;
- есть ли доступ к интернету;
- не вернул ли GREEN-API ошибку в интерфейсе приложения.

Если входящие сообщения не появляются, проверьте настройки получения уведомлений в личном кабинете GREEN-API.
